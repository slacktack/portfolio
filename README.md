# Tushar Gautam — portfolio

Next.js 16, React 19, Tailwind 4, Three.js, Motion, Lenis.

```bash
npm install
npm run dev     # http://localhost:3000
npm run build   # production build
```

Deploy: import the repo in Vercel. No environment variables are needed.

Content lives in `lib/site.ts`. The 3D project stage plays the recordings in `public/assets/video`.


If styles look stale in dev, run `npm run dev:fresh` (clears the cache and restarts).
